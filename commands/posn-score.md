บันทึกผลสอบของชุด `$1` ชุดที่ `$2`

## ถามผู้ใช้แค่ 2 คำถามนี้ ห้ามเกิน

พิมพ์สองบรรทัดนี้ออกไปแล้วรอคำตอบ:

```
ผิดข้อไหนบ้าง (คั่นด้วยเว้นวรรค):
ใช้เวลาไปกี่นาที:
```

**ห้ามถามอย่างอื่นเด็ดขาด** ห้ามถามว่าผิดเพราะอะไร ห้ามถามหัวข้อ ห้ามถามระดับความยาก
ห้ามถามว่ารู้สึกอย่างไร ห้ามถามว่าอยากบันทึกอะไรเพิ่มไหม

เหตุผล: ถ้าถาม 6 คำถาม ผู้ใช้จะเลิกกรอกภายในสองสัปดาห์ การกรอกที่ทำได้จริงทุกครั้ง
มีค่ากว่าการกรอกละเอียดที่ทำได้สามครั้งแล้วเลิก ส่วนที่เหลือ derive จากพิมพ์เขียวได้หมดอยู่แล้ว

ถ้าผู้ใช้ตอบว่าไม่ผิดเลย ให้ส่ง `--wrong ""` (สคริปต์รับได้)

## แล้วรัน

```bash
python3 ~/.claude/skills/posn/scripts/exam_result.py score $1 $2 \
    --wrong "<ที่ผู้ใช้ตอบ>" --minutes <ที่ผู้ใช้ตอบ>
```

สคริปต์อ่าน `blueprints/$1-set$2.json` แล้ว derive `by_topic` / `by_level` /
`est_min_total` เองทั้งหมด เขียนลง `~/Documents/POSN.Computer/results/$1-set$2.json`

## ถ้าสคริปต์ error ว่าไม่มีพิมพ์เขียว

บอกผู้ใช้ตรง ๆ ว่าชุดนี้ถูกสร้างโดยไม่ผ่าน `--json` จึงไม่มีข้อมูลว่าข้อไหนหัวข้ออะไร
แล้วให้คำสั่ง `exam_blueprint.py ... --json` ที่ต้องรันก่อน

**ห้ามถามหัวข้อรายข้อจากผู้ใช้มาแทน** และห้ามเดาหัวข้อเอง — ข้อมูลที่เดามาจะไปเพี้ยนต่อ
ใน `/posn-weakness` ซึ่งเป็นตัวชี้ว่าจะออกข้อสอบชุดหน้าเน้นอะไร

## รายงานผล

พิมพ์ output ของสคริปต์ให้ผู้ใช้ดู แล้วปิดท้ายด้วยบรรทัดเดียวว่าจะเจาะข้อไหนต่อได้ด้วย
`/posn-why $1 $2 <ข้อ>` — **ห้ามรันเอง ห้ามวิเคราะห์จุดอ่อนต่อในคำสั่งนี้**
(นั่นเป็นหน้าที่ของ `/posn-weakness` ซึ่งต้องใช้ข้อมูลหลายชุด)
