สร้างโจทย์ isomorphic variant จาก `$ARGUMENTS`

อ่าน `~/.claude/skills/posn/docs/VARIANT.md` ให้จบก่อนลงมือ — ขั้นตอนบังคับ 7 ข้ออยู่ในนั้น
สรุปที่ต้องทำจริง:

## 1. หา `idea` ต้นฉบับ

| source หน้าตาแบบ | ทำอะไร |
|---|---|
| `comp-set2#7` | `grep` จาก `~/Documents/POSN.Computer/index.jsonl` ได้ `idea` ตรง ๆ |
| `real-68-math#12` | เปิด PDF ข้อสอบจริงอ่าน แล้ว**สกัด**เป็นโครงคิดนามธรรม |
| ผู้ใช้แปะโจทย์มาเอง | สกัดจากข้อความที่วาง |

ถ้าเป็น `comp-setN#n` แล้วหาไม่เจอใน `index.jsonl` → **หยุด** บอกผู้ใช้ว่าชุดนั้นยังไม่ได้
บันทึกดัชนี ห้ามไปเปิด PDF ชุดเก่ามาเดาไอเดียแทน

## 2. เช็คเพดานก่อนสร้าง

```bash
python3 ~/.claude/skills/posn/scripts/exam_index.py variants <source>
```

เกิน 5 ข้อ → เตือนผู้ใช้ว่ากำลังฝึกไอเดียเดิมมากเกินไป **แล้วถามก่อนทำต่อ**

## 3. สร้าง variant ทีละข้อ (ปริยาย 3 ข้อ)

- **เปลี่ยนพื้นผิวอย่างน้อย 2 อย่างพร้อมกัน**: ตัวเลข **และ** บริบทเรื่องราว
  เปลี่ยนแค่ตัวเลขไม่พอ — ผู้ใช้จะจำคำตอบเดิมได้ทันที
- **ตรวจ invariant**: ตัวเลขชุดใหม่ต้องไม่เปิดทางลัดที่ไม่มีใน `idea` เดิม
  (บังเอิญลงตัวสวยจนมองออกทันที = พัง) → สุ่มตัวเลขใหม่ **ห้ามแก้ `idea` ให้เข้ากับตัวเลข**
- **ตรวจระดับ**: จัดระดับ L ใหม่ เลื่อนจากต้นฉบับเกิน 1 ขั้น → สุ่มใหม่
  **ห้ามยอมรับแล้วแก้ป้ายระดับแทน**
- **ตัวลวงคำนวณใหม่ใน `verify.py` จาก `D[]`** ห้ามแปลงตัวลวงเดิมตามสัดส่วนตัวเลข
  เพราะความผิดที่นำไปสู่ตัวลวงไม่ได้ scale เชิงเส้นเสมอไป

ทั้งสามข้อนี้ถ้าไม่ผ่าน **ให้สุ่มใหม่ ไม่ใช่ลดเกณฑ์** — variant ที่ระดับเลื่อนหรือ invariant พัง
คือโจทย์คนละข้อ ซึ่งไม่ได้ฝึกสิ่งที่ผู้ใช้ตั้งใจจะฝึก

## 4. เพดานลิขสิทธิ์ (กฎเหล็กข้อ 10)

ถ้า source เป็นข้อสอบจริง: **ห้ามเขียนถ้อยคำจากข้อสอบจริงลงไฟล์ใด ๆ** รวมทั้ง scratchpad
และ `ideas.json` — บันทึกออกมาได้แค่ `idea` ที่เป็นโครงคิดนามธรรม
ถ้า `idea` ที่สกัดมายังติดบริบทเดิม ให้ตัดออกอีกชั้นจนเหลือแต่โครงคิด

## 5. ส่งมอบ

ถ้าผู้ใช้จะเอา variant ไปประกอบเป็นชุดข้อสอบ ให้เข้าไปป์ไลน์ปกติ (พิมพ์เขียว → verify →
preflight) และในชุดเดียว **ห้ามมี `variant_of` ชี้ต้นฉบับเดียวกันเกิน 1 ข้อ**

ถ้าผู้ใช้แค่อยากได้โจทย์ฝึกลอย ๆ ไม่ต้องทำ PDF ก็พิมพ์โจทย์ + เฉลยย่อให้ดูในแชทได้
แต่**ยังต้องรัน `verify.py` จริง** ก่อนบอกคำตอบ — กฎเหล็กข้อ 3 ไม่มีข้อยกเว้น
