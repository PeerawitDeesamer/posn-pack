รัน

```bash
python3 ~/.claude/skills/posn/scripts/exam_result.py weakness
```

สคริปต์อ่าน `~/Documents/POSN.Computer/results/*.json` ทั้งหมด + `index.jsonl`
แล้วนับให้เอง **อย่าคิดเลขเอง อย่าสรุปนอกเหนือจากตัวเลขที่สคริปต์พิมพ์ออกมา**

## กฎการรายงาน

1. **แสดงตัวหารเสมอ** — เขียน `pyloop 3/6` ห้ามเขียนแค่ `50%` ตัวหารคือสิ่งที่บอกว่า
   ตัวเลขนั้นเชื่อได้แค่ไหน ตัดทิ้งเมื่อไหร่คือเปิดทางให้ตีความเกินข้อมูล
2. **หัวข้อที่มีป้าย (ข้อมูลน้อย)** ให้คงป้ายไว้ตอนเล่าให้ผู้ใช้ฟัง และ**ห้ามสรุปอะไรจากมัน**
   ห้ามพูดว่า "อ่อน pymix มาก" เพราะผิด 5/5 จากชุดเดียว
3. **ถ้าสคริปต์บอกว่ายังสรุปไม่ได้ (< 3 ชุด)** → บอกผู้ใช้ตรง ๆ ตามนั้นแล้ว**หยุด**
   ห้ามเดา pattern ห้ามหาทางสรุปจากข้อมูลที่มี ห้ามเสนอชุดถัดไป
   นี่คือกฎเดียวกับกฎเหล็กข้อ 3 (ห้ามเดาคำตอบ) — สถิติจาก n=4 หลอกได้ง่ายพอ ๆ กับ
   การไล่โจทย์ด้วยตา
4. **คำสั่ง `exam_blueprint.py --focus` ที่สคริปต์พิมพ์ออกมา ให้ส่งต่อให้ผู้ใช้เฉย ๆ**
   ห้ามรันเอง ผู้ใช้เป็นคนตัดสินใจว่าจะซ้อมเรื่องไหนต่อ และต้องเลือกเลขชุดเอง
5. ถ้าสคริปต์รายงานว่า**ผิดซ้ำในไอเดียเดียวกันเกิน 2 ครั้ง** ให้ส่งต่อคำสั่ง
   `/posn-variant <ต้นฉบับ>` ที่สคริปต์พิมพ์มาด้วย — ก็**ห้ามรันเอง**เช่นกัน

## สรุปให้ผู้ใช้

ปิดท้ายด้วย 3-5 บรรทัด: จุดอ่อนอันดับ 1-2 พร้อมตัวหาร, มีอะไรที่ข้อมูลยังไม่พอบ้าง,
และคำสั่งที่ผู้ใช้เลือกรันต่อได้ ห้ามยาวกว่านี้ — รายงานที่ยาวจนไม่มีใครอ่านคือรายงานที่ตายแล้ว
