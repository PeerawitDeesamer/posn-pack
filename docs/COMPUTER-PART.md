พาร์ทนี้ในข้อสอบจริงคือ "ตอนที่ 2-3" ของปี 68 (ปรนัย 25 + อัตนัย 5)

3. เนื้อหาเดียวกับข้อ 2 แบบอัตนัยเติมคำตอบ

## ขอบเขตภาษาไพธอนที่ใช้ได้ (เกินนี้ห้ามเด็ดขาด)

**ใช้ได้**

- กำหนดค่าตัวแปร `=`
- นิพจน์คำนวณ `+ - * / // % **`
- นิพจน์เปรียบเทียบ `== != < <= > >=`
- ตัวเชื่อมตรรกะ `not and or`
- `if` เดี่ยว, `if-else`, `if` ซ้อน `if`
- `while` และการผสม `if` กับ `while`
- **ลูปซ้อน ไม่เกิน 2 ชั้น**
- **อาเรย์ 1 มิติ และการเข้าถึงสมาชิกด้วยดัชนี `a[i]`**
- `print()`

**ห้ามใช้** (นอกขอบเขต ถึงจะเขียนง่ายกว่าก็ห้าม)

- `def` ฟังก์ชัน / `return` / `lambda` — ประกาศห้ามไว้ตรง ๆ
- `for` และ `range()` — ต้องเขียนเป็น `while` เสมอ
- ลูปซ้อนเกิน 2 ชั้น · อาเรย์ 2 มิติขึ้นไป
- `dict` `set` `tuple` และ list method (`.append()` `.sort()`)
- `import` อะไรก็ตาม
- `.split()` และ f-string · `try/except`

**ใช้ได้ ถ้าใส่หมายเหตุอธิบายไว้ในโจทย์** — ทั้งหมดนี้ข้อสอบจริงใช้เอง

| สิ่งที่ใช้ | ปรากฏที่ |
|---|---|
| `elif` | ปี 67 ข้อ 42, 45, 48, 49 · ปี 68 ข้อ 42 |
| `continue` / `break` | ปี 68 ข้อ 33 |
| `len()` | ปี 68 ข้อ 43, 44, 45 |
| `.lower()` `.upper()` | ปี 68 ข้อ 45 |
| สตริงเป็นข้อมูลนำเข้า | ปี 68 ข้อ 45, 54 |

ส่วนที่ยังห้ามอยู่เป็นการตั้งเข้มกว่าประกาศ — ไม่เคยพบในข้อสอบจริงปี 64-68
และมันดึงความสนใจจากตรรกะไปที่ไวยากรณ์ ทั้งที่ประกาศบอกว่า **"ไม่เน้นการเขียนตาม
ไวยากรณ์ของภาษา"**

**อาเรย์ให้เขียนเป็นค่าคงที่ในโจทย์** แล้วไล่สมาชิกด้วย `while` กับดัชนี เช่น

```python
a = [4, 9, 2, 7, 5]
i = 0
s = 0
while i < 5:
    if a[i] % 2 == 1:
        s = s + a[i]
    i = i + 1
print(s)
```

ห้ามใช้ `len(a)` — เขียนจำนวนสมาชิกเป็นตัวเลขไปเลย เพราะโจทย์บอกอยู่แล้วว่ามีกี่ตัว

ตัวไหนที่นักเรียนอาจไม่คุ้น (`//` `%` `**` `!=`) ให้ใส่ `\note{}` อธิบายไว้ใต้โจทย์
ข้อสอบจริงอธิบายทุกครั้ง อย่าถือว่ารู้แล้ว

**โจทย์ที่เป็นขั้นตอนวิธีเชิงบรรยาย** (ขั้นตอนที่ 1), 2), 3) …) ไม่ต้องใช้ไวยากรณ์ไพธอน
เขียนเป็นภาษาไทยเป็นขั้น ๆ ได้เลย — ข้อสอบจริงใช้ทั้งสองแบบพอ ๆ กัน

## กฎเหล็กเฉพาะพาร์ทนี้

1. **โปรแกรมทุกชิ้นในโจทย์ต้องรันจริงใน `verify.py`** ห้ามไล่ด้วยตาแล้วเชื่อ
   ก๊อปโค้ดจากโจทย์มาวางแล้วรัน แล้วเทียบเอาต์พุตกับตัวเลือกที่จะพิมพ์
2. **โค้ดในโจทย์กับโค้ดใน `verify.py` ต้องเป็นข้อความเดียวกันเป๊ะ** วิธีที่กันพลาดได้จริงคือ
   เก็บโค้ดเป็นสตริงตัวเดียวใน `verify.py` แล้ว `exec()` มัน และ `print()` สตริงเดียวกันนั้น
   ออกมาวางในไฟล์ `.tex` — อย่าพิมพ์ซ้ำสองที่
3. **ต้องเช็คว่าลูปหยุดจริง** ก่อน `exec` ใส่ตัวนับรอบ ถ้าเกิน 10⁶ รอบให้ error
   ข้อที่ตั้งใจให้ลูปไม่หยุดต้องพิสูจน์ว่าไม่หยุดด้วยเหตุผล ไม่ใช่ปล่อยให้สคริปต์ค้าง
4. **ตัวลวงทุกตัวต้องคำนวณจริงใน `D[]`** ไม่ใช่แค่ "ควรมาจากความผิดที่เกิดจริง"
   แต่ต้องรันโค้ดของความผิดนั้นออกมาเป็นตัวเลข เช่น ค่าที่ได้ถ้าออกจากลูปช้าไป 1 รอบ,
   ค่าที่ได้ถ้าสลับลำดับสองบรรทัด, ค่าที่ได้ถ้าใช้ `/` แทน `//` — ดูโครงข้างล่าง
5. **ห้ามให้ผลลัพธ์เป็นทศนิยมยาว** ถ้าโจทย์ใช้ `/` ให้ออกแบบเลขให้หารลงตัว
   หรือเปลี่ยนเป็น `//` ตั้งแต่แรก
6. **การจัดรูปโค้ดใน LaTeX** ใช้ `verbatim`-style ที่ฟอนต์ monospace และรักษาย่อหน้า
   ระดับการเยื้อง (indent) คือความหมายของโปรแกรม เยื้องเพี้ยน = โจทย์ผิด ต้องดูจากภาพ PNG ทุกข้อ

## โครงร่าง verify.py ของพาร์ทคอม

`R[n]` = คำตอบถูก `D[n]` = ตัวลวง **ทั้งสองอย่างมาจากการรันโค้ด ไม่ใช่จากหัว**
หลักการเต็มและตัวอย่างพาร์ทคณิต ดู [VERIFY.md](VERIFY.md)

```python
import io, sys, ast
from pathlib import Path
sys.path.insert(0, str(Path.home() / '.claude/skills/posn/scripts'))
from verify_lib import emit

# โค้ดในโจทย์กับที่รันต้องเป็นสตริงเดียวกัน — พิมพ์ครั้งเดียว ใช้สองที่
Q3 = '''
x = 2
while x < 20:
    x = x + 5
    if x % 3 == 0:
        x = x - 1
print(x)
'''


def max_loop_depth(node, depth=0):
    """ประกาศขอบเขตอนุญาตลูปซ้อนไม่เกิน 2 ชั้น — ต้องตรวจ ไม่ใช่เชื่อสายตา"""
    here = depth + 1 if isinstance(node, ast.While) else depth
    return max([here] + [max_loop_depth(c, here) for c in ast.iter_child_nodes(node)])


def run(src, limit=10**6):
    """รันโค้ดโจทย์ พร้อมกันไวยากรณ์นอกขอบเขตและลูปไม่รู้จบ คืนสิ่งที่ print ออกมา"""
    tree = ast.parse(src)
    # อาเรย์ 1 มิติกับดัชนี (ast.List / ast.Subscript) อยู่ในขอบเขต จึงไม่อยู่ในรายการนี้
    for node in ast.walk(tree):
        if isinstance(node, (ast.For, ast.FunctionDef, ast.Import, ast.ImportFrom,
                             ast.ListComp, ast.Dict, ast.Set, ast.Lambda)):
            raise SystemExit(f'โจทย์ใช้ {type(node).__name__} ซึ่งอยู่นอกขอบเขตข้อสอบ')
    if max_loop_depth(tree) > 2:
        raise SystemExit('ลูปซ้อนเกิน 2 ชั้น ซึ่งเกินขอบเขตที่ประกาศไว้')
    steps = [0]

    def guard(frame, event, arg):
        steps[0] += 1
        if steps[0] > limit:
            raise RuntimeError(f'ลูปไม่หยุดภายใน {limit} ขั้น')
        return guard

    buf, old = io.StringIO(), sys.stdout
    sys.stdout = buf
    sys.settrace(guard)
    try:
        exec(compile(tree, '<q>', 'exec'), {})
    finally:
        sys.settrace(None)
        sys.stdout = old
    return buf.getvalue().strip()


R, D = {}, {}

R[3] = run(Q3)
# ตัวลวงของพาร์ทคอม = "รันโค้ดที่ผิดไปแบบที่นักเรียนพลาดจริง" แล้วเอาผลมาใช้
D[3] = {
    'ลืมบรรทัด x = x - 1':      run(Q3.replace('        x = x - 1\n', '')),
    'ออกจากลูปช้าไป 1 รอบ':     run(Q3.replace('while x < 20', 'while x <= 20')),
    'ใช้ / แทน % ตอนเช็คหาร 3': run(Q3.replace('x % 3 == 0', 'x // 3 == 0')),
}

for n in sorted(R):
    print(f'ข้อ {n} → {R[n]}   ตัวลวง {list(D[n].values())}')

emit(R, D, 'comp', 3)      # ตรวจตัวลวง แล้วเขียน verify_out.json
```

`emit()` จะหยุดด้วย `VerifyError` ถ้า **ตัวลวงตัวไหนเท่ากับคำตอบถูก** (= ข้อนั้นมีคำตอบถูก
2 ตัว) ถ้าตัวลวงสองตัวในข้อเดียวกันได้ค่าเท่ากัน (= ตัวเลือกจริงเหลือ 3 ตัว)
หรือถ้าข้อปรนัยข้อไหนมีตัวลวงไม่ครบ 3 ตัว

เขียน `print(f'ข้อ N → {R[N]}')` ให้ครบทุกข้อ แล้ว **ก๊อปค่าจากเอาต์พุตไปวางในตัวเลือก**
ห้ามพิมพ์ตัวเลขจากที่คิดในหัว

สำหรับข้อ `algocount` ให้ใส่ตัวนับลงในโค้ดที่รัน (แต่ไม่ใส่ในโจทย์) แล้ว print ค่าตัวนับออกมา
ตัวลวงที่ใช้ได้ดีของ `algocount` คือ "นับรอบสุดท้ายด้วย" กับ "นับเฉพาะรอบที่เข้า if"

|---|---|---|

| ข้อ `algocount` เถียงได้ว่านับอะไร | โจทย์ไม่ได้ระบุว่านับ "การเปรียบเทียบ" หรือ "รอบ" | เขียนให้ชัดว่านับคำสั่งบรรทัดไหน |
