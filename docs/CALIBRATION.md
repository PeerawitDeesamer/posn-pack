# เพดานความยากจริง — สำรวจจากข้อสอบจริงปี 66-68

**เอกสารนี้มีอำนาจเหนือความรู้สึกว่า "ข้อนี้น่าจะพอดี"** ถ้าโจทย์ที่กำลังจะเขียน
ยากกว่าอะไรก็ตามในบัญชีข้างล่างนี้ แปลว่าเกินเพดาน ต้องเขียนใหม่ ไม่ใช่ปรับป้าย L

เขียนขึ้นหลังพบว่าชุดที่ 5 (both-set5) ออกมายากเกินจริงมากทั้งฉบับ
สาเหตุคือ `DIFFICULTY.md` เดิมชี้ไปทางแนวโอลิมปิก (อินแวเรียนต์ รังนกพิราบ
พิสูจน์ขอบล่าง) ซึ่ง **ไม่ใช่แนวของข้อสอบคัดเข้าค่าย 1**

## พาร์ทวิทยาการคำนวณ — ของจริงคืออะไร

### บัญชีข้อสอบจริงปี 68 (ข้อ 31-60) เรียงตามแนว

| แนว | จำนวน | ตัวอย่างจากของจริง |
|---|---|---|
| ประเมินนิพจน์ / ไวยากรณ์ | 2 | ค่าของ `2*3**3+10/2` · `(x % 2 > 0) != (x > 0)` เป็น True เมื่อใด |
| ไล่ `if`/`if` ซ้อน | 3 | ราคาตั๋วหนัง 4 กรณี ถามว่าอินพุตใดได้ 80 บาท |
| ไล่ลูป `while` สั้น | 6 | `x=5; while x>0: x=x-2 ...` พิมพ์อะไร · `a=95,b=0` จบแล้วได้ค่าอะไร |
| นับรอบ / นับจำนวนที่พิมพ์ | 3 | ลูปซ้อนพิมพ์ `*` กี่ครั้ง (ตอบ 21) · นับพหุคูณของ 7 หรือ 11 |
| เทียบโปรแกรมหลายเวอร์ชัน | 2 | โปรแกรม A-D อันไหนคำนวณผลรวมที่โจทย์เขียนไว้ |
| ดำเนินการกับอาเรย์/สตริง | 3 | หมุนอาเรย์ 2 ครั้ง · นับคู่ที่บวกกันได้ 7 · สลับพิมพ์เล็ก-ใหญ่ |
| ปริศนาตรรกะภาษาไทย | 4 | กล่องทอง-เงินติดป้ายผิด · เรียงแถวเด็ก 5 คน · คัดเลือกเข้าชมรม |
| โจทย์สถานการณ์ต้องจำลองตาม | 5 | แจกลูกอม · ถังน้ำมันรั่ว · คิวคืนหนังสือ · สปริงเกอร์คลุมสนาม |
| อ่านรหัสเทียมแล้วทำตาม | 3 | หาค่าเฉลี่ยแล้วนับตัวที่มากกว่า · ไวยากรณ์ `(01)*00(11)*` |
| กราฟ/เส้นทาง | 1 | เส้นทางสั้นสุด A→E บนกราฟ 5 จุด 7 เส้น |

**ข้อที่ยากที่สุดของทั้งฉบับปี 68** คือเส้นทางสั้นสุดบนกราฟ 5 จุด กับเลือกสปริงเกอร์
ให้คลุมสนามยาว 20 เมตรจาก 8 ตัว — ทั้งคู่ทำด้วยมือได้ในไม่กี่นาที นั่นคือ **เพดาน**

ปี 67 ต่ำกว่านั้นอีก ข้อ 41-49 เป็น `if`/`elif` กับนับรอบลูปล้วน ๆ

### ห้ามออก — เกินเพดานชัดเจน

อัลกอริทึมที่มีชื่อและต้องรู้จักมาก่อนจึงทำได้ทัน **ไม่เคยปรากฏในข้อสอบจริงเลยสักปี**

- โจเซฟัส (ทิ้งใบหนึ่ง ย้ายใบหนึ่ง หาผู้รอด)
- Boyer-Moore หาเสียงข้างมากด้วยตัวนับหักล้าง
- นับจำนวนการเปรียบเทียบของ insertion sort / binary search กรณีแย่สุด
- คอลแลตซ์แบบไล่ย้อนหา n ที่ให้จำนวนก้าวพอดี
- ยุคลิดกรณีแย่สุด = คู่ฟีโบนักชีติดกัน
- อินแวเรียนต์พาริตี ตอบว่า "เป็นไปไม่ได้"
- รวมกองหินด้วยต้นทุนต่ำสุด (ฮัฟฟ์แมน)
- นับคู่ที่ผลคูณเป็นกำลังสองด้วยส่วนที่ปลอดกำลังสอง
- แทรกวงเล็บให้สมดุลน้อยที่สุด

**เส้นแบ่ง** — โจทย์ต้องทำได้ด้วย "อ่านให้ละเอียดแล้วไล่ตาม" หรือ "ลองสองสามกรณีแล้วเห็นแบบแผน"
ถ้าต้องรู้ชื่อวิธีหรือทฤษฎีบทมาก่อนจึงจะทำทัน = เกินเพดาน

### สิ่งที่ของจริงทำ แต่เราเคยห้ามตัวเองไว้ผิด ๆ

ข้อสอบจริงปี 68 **ใช้** `len()` (ข้อ 43, 44) และ `.lower()` `.upper()` พร้อม `หมายเหตุ`
อธิบายความหมาย (ข้อ 45) ปี 67 **ใช้** `elif` เป็นปกติ (ข้อ 42, 45, 48, 49)
และปี 68 ข้อ 33 **ใช้** `continue`

ใช้ได้ทั้งหมด ตราบที่ใส่ `\note{}` อธิบายตัวที่นักเรียนอาจไม่คุ้น เหมือนที่ของจริงทำ

## พาร์ทคณิตศาสตร์ — แนวของจริง ไม่ใช่แบบฝึกหัด ม.ต้น

ของจริงเป็น **ปริศนาเชิงเทคนิค** ไม่ใช่โจทย์ปัญหาชีวิตประจำวัน

### แนวที่ปรากฏจริง

| แนว | ตัวอย่างจากปี 66-68 |
|---|---|
| เศษเหลือ/มอดุลาร์ | ผลบวก n<1000 ที่หารด้วย 7, 10, 13 เหลือเศษ 1 · แก้ `2x+3 ≡ 4 (mod 11)` |
| เลขโดดและการหารลงตัว | `4a1b4c9` หารด้วย 11 ลงตัว · หลักหน่วยของผลคูณเลขยกกำลัง |
| จำนวนเฉพาะ | นับจำนวนเฉพาะในช่วง · ตรวจว่า 1,010,011 เป็นจำนวนเฉพาะไหม |
| สมบัติของฟังก์ชัน | โดเมน หนึ่งต่อหนึ่ง เส้นกำกับ · หา `f∘g⁻¹` |
| อสมการ | อสมการค่าสัมบูรณ์ที่มีเศษส่วน · หาขอบเขตจากอสมการสองชั้น |
| ตรรกศาสตร์เชิงสัญลักษณ์ | ตาราง P Q R หา tautology · ตัวบ่งปริมาณซ้อน · บัตร Wason |
| เซตที่มีเงื่อนไข | นับ `n(B−A)` จากเงื่อนไขอสมการ · "เซตดี" ที่ x กับ 2x อยู่ด้วยกันไม่ได้ |
| การนับ | สัมประสิทธิ์ `x³y⁷` จาก `(2x+y)¹⁰` · นับตามเงื่อนไข |
| ตัวดำเนินการที่นิยามเอง | นิยาม `?` และ `@` แล้วให้หาค่าของนิพจน์ผสม |

### ห้ามออก — ผิดแนว

โจทย์คำนวณแบบแบบฝึกหัด ม.ต้น **ไม่มีในข้อสอบจริงเลย**

- อัตราเร็วเฉลี่ยไป-กลับ (ค่าเฉลี่ยฮาร์มอนิก)
- อัตราส่วน `a:b = 3:4`, `b:c = 6:7` แบ่งผลรวม
- ผสมสารละลาย เติมน้ำให้ความเข้มข้นลดลง
- โจทย์งาน-อัตราเร็ว-คนทำงานร่วมกัน
- เรขาคณิตแบบแทนสูตร (วงกลมสัมผัสกัน หาเส้นสัมผัสร่วม)

### เรื่องสัญลักษณ์ — เอกสารขอบเขตกับข้อสอบจริงไม่ตรงกัน

`เนื้อหาที่ใช้สอบ.pdf` เขียนว่า "ไม่เน้นสัญลักษณ์เฉพาะทาง ให้ใช้รูปการบรรยาย"
แต่ข้อสอบจริงใช้ `ℝ ∈ ⊆ ≡ (mod n) ∘ ¬ → ∧ ∀ ∃` เต็มไปหมดทั้งปี 66, 67, 68

**ให้ทำตามข้อสอบจริง** — ใช้สัญลักษณ์ได้ตามปกติ แต่ตัวดำเนินการที่ไม่ใช่มาตรฐาน
(`≡ (mod n)`, ตัวดำเนินการนิยามเอง) ต้องมี `หมายเหตุ` อธิบาย เหมือนที่ของจริงทำทุกครั้ง
