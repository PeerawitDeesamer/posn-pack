# สเปกข้อสอบ — ถามให้ครบก่อนลงมือ

ข้อสอบชุดหนึ่งกำหนดด้วย 6 ค่า ถ้าผู้ใช้ไม่ระบุ ให้ใช้ค่าปริยาย **แต่ต้องพูดออกมาก่อนเริ่มเสมอ**
ว่าจะใช้อะไร ผู้ใช้จะได้ทักท้วงทัน (แก้ตอนวางแผน 1 นาที แก้ตอนเขียนเสร็จแล้ว 2 ชั่วโมง)

| ค่า | ตัวเลือก | ปริยาย |
|---|---|---|
| `part` พาร์ท | `math` คณิตศาสตร์ / `comp` วิทยาการคำนวณ / `both` ทั้งฉบับ | `math` |
| `format` รูปแบบ | `mcq` ปรนัย / `fill` อัตนัยเติมคำตอบ / `mixed` ผสม | คณิต=`mcq`, คอม=`mixed` |
| `difficulty` ความยาก | `easy` / `standard` / `hard` / `brutal` | `standard` |
| `focus` เรื่องที่เน้น | รหัสหัวข้อ คั่นด้วย `,` (ดู `--list`) | ไม่เน้น = กระจายตามน้ำหนัก |
| `count` จำนวนข้อ | ตัวเลข หรือ 0 = ใช้โครงปีจริง | คณิต 50 / คอม 30 / both ตามปี 68 |
| `set` เลขชุด | ตัวเลข | เลขถัดจากชุดล่าสุดในโฟลเดอร์ |

## แปลคำสั่งผู้ใช้เป็นสเปก

| ผู้ใช้พูดว่า | สเปกที่ได้ |
|---|---|
| "สร้างข้อสอบเทียม ชุดที่ 8" | `--part math --difficulty standard --count 50 --set 8` |
| "ขอพาร์ทคอม ชุดที่ 2" | `--part comp --format mixed --count 30 --set 2` |
| "ขอพาร์ทคอมแบบอัตนัยล้วน 10 ข้อ" | `--part comp --format fill --count 10` |
| "ขอชุดยาก ๆ เน้นเรื่องลูป" | `--part comp --difficulty hard --focus pyloop,pymix` |
| "ขอคณิตเน้นเรขาคณิตกับการนับ" | `--part math --focus geometry,counting` |
| "ขอเหมือนข้อสอบจริงปี 68 ทั้งฉบับ" | `--part both --year 68 --difficulty standard` |
| "ขอชุดง่าย ๆ ไว้วอร์ม" | `--difficulty easy` |
| "ขอโหดสุด" | `--difficulty brutal` |

**สิ่งที่ต้องถามกลับ ไม่ต้องเดา** — ถามรวมทีเดียว อย่าถามทีละคำถาม

- ขอ "พาร์ทคอม" แต่ไม่บอกว่าเอาอัตนัยด้วยไหม → ถ้าไม่ตอบ ใช้ `mixed` (ตรงข้อสอบจริง)
- ขอ "เน้นเรื่อง X" แต่ X ไม่อยู่ในขอบเขต `เนื้อหาที่ใช้สอบ.pdf` → บอกตรง ๆ ว่าอยู่นอกขอบเขต
  แล้วเสนอหัวข้อที่ใกล้ที่สุด **ห้ามออกข้อนอกขอบเขตเงียบ ๆ**
- ขอจำนวนข้อที่ทำให้เวลาสอบเกิน 3 ชม. → สร้างพิมพ์เขียวก่อน แล้วให้ผู้ใช้ตัดสินใจจากตัวเลขจริง

## สร้างพิมพ์เขียวก่อนเขียนโจทย์

```bash
python3 ~/.claude/skills/posn/scripts/exam_blueprint.py \
    --part comp --format mixed --difficulty hard --focus pyloop,algocount --count 30 --set 2
```

ได้ตาราง "ข้อที่ / หัวข้อ / ระดับ / รูปแบบ" + โควตาที่ต้องคุม + ชื่อไฟล์ + รหัสชุดวิชา
**ก๊อปตารางนี้ไปวางเป็นคอมเมนต์หัวไฟล์ `verify.py`** แล้วเขียนโจทย์ไล่ตามตาราง
เขียนจบแล้วย้อนเช็คว่าแต่ละข้อยังตรงระดับที่วางไว้จริงหรือไม่

พิมพ์เขียวเป็นแค่โครง ไม่ใช่คำสั่งตายตัว — ถ้าเขียนจริงแล้วหัวข้อไหนออกไม่สวย
สลับหัวข้อได้ แต่ **ห้ามลดระดับความยากรวมของชุด** ให้หาข้ออื่นในระดับเดิมมาแทน

`--seed` ล็อกผลสุ่มไว้ ถ้าไม่ใส่จะใช้เลขชุดเป็น seed — พิมพ์เขียวของชุดเดิมจึงออกมาเหมือนเดิมทุกครั้ง

## รหัสชุดวิชาบนปก

`0000` + หลักพาร์ท + เลขชุด 2 หลัก

| พาร์ท | หลักพาร์ท | ตัวอย่าง ชุดที่ 3 |
|---|---|---|
| คณิตศาสตร์ | 0 | `0000003` |
| วิทยาการคำนวณ | 1 | `0000103` |
| ทั้งฉบับ | 2 | `0000203` |

## ข้อความบนปกที่ต้องเปลี่ยนตามสเปก

- ชื่อพาร์ท: "พาร์ทคณิตศาสตร์" / "พาร์ทคอมพิวเตอร์ (วิทยาการคำนวณ)" / ไม่ระบุ (ฉบับเต็ม)
- คำชี้แจงข้อ 1 ต้องบอกจำนวนข้อแยกตอน และคะแนนต่อข้อให้ตรงพิมพ์เขียว
- ถ้ามีตอนอัตนัย ต้องมีคำชี้แจง "เขียนตอบเฉพาะตัวเลขคำตอบ ซึ่งเป็นจำนวนเต็มไม่เกิน 4 หลัก
  โดยให้ตัวเลขคำตอบด้านขวาตรงกับหลักหน่วย ห้ามใช้เครื่องคำนวณ"
- ถ้ามีพาร์ทคอม ต้องมีคำชี้แจงว่าโปรแกรมเขียนด้วยภาษา Python และใช้เฉพาะคำสั่งในขอบเขต
- ข้อสุดท้ายของคำชี้แจงคือ disclaimer ว่าเป็นข้อสอบเทียม ไม่ใช่ข้อสอบจริงของมูลนิธิ สอวน.
