# Isomorphic Variant — เลียนแบบโจทย์โดยเปลี่ยนพื้นผิว

## ที่มา

กฎเหล็กข้อ 7 มีบททดสอบ *"เปลี่ยนตัวเลขในโจทย์ ต้องออกแรงเท่าเดิมไหม"* ซึ่งใช้ **คัดโจทย์ทิ้ง**
งานนี้คือการกลับด้านมันมาใช้ **สร้างโจทย์** — ถ้าข้อหนึ่งผ่านบททดสอบนั้น แปลว่าเปลี่ยนตัวเลข
แล้วยังวัดไอเดียเดิมได้ ซึ่งก็คือนิยามของโจทย์ฝึกซ้ำที่ดี

ใช้เมื่อผู้ใช้เจอข้อที่ทำไม่ได้ แล้วอยากฝึกไอเดียนั้นซ้ำด้วยโจทย์ที่จำคำตอบไม่ได้

## คำสั่ง

```
/posn-variant <source> [--count N]        # ปริยาย --count 3
```

| แบบของ `source` | รูปแบบ | ที่มาของ idea |
|---|---|---|
| ชุดเทียมเก่า | `comp-set2#7` | อ่าน `index.jsonl` ได้ `idea` ตรง ๆ ไม่ต้องสกัด |
| ข้อสอบจริง | `real-68-math#12` | ต้องสกัดจาก PDF (ดูเพดานลิขสิทธิ์ข้างล่าง) |
| วางโจทย์สด | ผู้ใช้แปะข้อความมาเอง | สกัดจากข้อความที่วาง |

## ขั้นตอนบังคับ

**1. สกัดไอเดีย** ได้ `idea` เป็นประโยคเดียวแบบเดียวกับที่ `index.jsonl` เก็บอยู่แล้ว
ต้องเป็น**โครงคิด ไม่ใช่เนื้อโจทย์**

**2. เปลี่ยนพื้นผิวอย่างน้อย 2 อย่างพร้อมกัน** — ตัวเลข **และ** บริบทเรื่องราว
ห้ามเปลี่ยนแค่ตัวเลขอย่างเดียว เพราะจะยังเห็นชัดว่ามาจากไหน และผู้ใช้จะจำคำตอบเดิมได้

**3. ตรวจว่า invariant ไม่พัง** รันบททดสอบกฎเหล็กข้อ 7 ย้อนกลับ: ถ้าตัวเลขชุดใหม่ทำให้
ตอบได้ด้วยทางลัดที่ไม่มีใน `idea` เดิม (เช่นบังเอิญลงตัวสวยจนมองออกทันที)
→ **สุ่มตัวเลขใหม่ ห้ามใช้ชุดที่พัง** และ**ห้ามแก้ `idea` ให้เข้ากับตัวเลข**

**4. ตรวจว่าระดับไม่เลื่อน** จัดระดับ L ใหม่หลังเปลี่ยนตัวเลข ถ้าเลื่อนจากต้นฉบับเกิน 1 ขั้น
→ สุ่มใหม่ **ห้ามยอมรับแล้วแก้ป้ายระดับแทน**

**5. ตัวลวงคำนวณใหม่จาก `D[]`** ตาม [VERIFY.md](VERIFY.md) **ห้ามแปลงตัวลวงเดิมตามสัดส่วน
ตัวเลข** เพราะความผิดที่นำไปสู่ตัวลวงไม่ได้ scale เชิงเส้นเสมอไป — คนที่ "ลืมกรณี $n$ คู่"
ในโจทย์ใหม่อาจได้ตัวเลขที่ไม่ได้เป็นสัดส่วนกับของเดิมเลย

**6. บันทึกลง `index.jsonl`** ผ่าน `ideas.json` โดยเพิ่ม field `variant_of`

```json
{"3": {"level": 4, "idea": "...", "variant_of": "comp-set2#7"}}
```

**7. เพดานความหลากหลาย** ก่อนสร้าง ให้นับก่อน

```bash
python3 ~/.claude/skills/posn/scripts/exam_index.py variants comp-set2#7
```

เกิน 5 ข้อ → สคริปต์เตือนว่ากำลังฝึกไอเดียเดิมมากเกินไป **ถามผู้ใช้ก่อนทำต่อ**
และในชุดข้อสอบชุดเดียว **ห้ามมี `variant_of` ที่ชี้ต้นฉบับเดียวกันเกิน 1 ข้อ**
(`exam_index.py check` ตรวจให้)

## เพดานลิขสิทธิ์ — กฎเหล็กข้อ 10

ไอเดียทางคณิตศาสตร์ไม่มีลิขสิทธิ์ แต่ถ้อยคำและบริบทที่แต่งขึ้นมีลิขสิทธิ์
เส้นแบ่งระหว่าง "เลียนแบบไอเดีย" กับ "ดัดแปลงงานต้นฉบับ" อยู่ตรง**ความเป็นนามธรรมของ `idea`**

> **ห้ามเขียนถ้อยคำจากข้อสอบจริงลงไฟล์ใด ๆ** ไม่ว่า `.tex` `.py` `.json` `.md` หรือ scratchpad
> แม้เป็นการอ้างอิงชั่วคราว — อ่านจาก PDF ได้ แต่สิ่งที่บันทึกออกมาได้มีอย่างเดียวคือ `idea`
> ที่เป็นโครงคิดนามธรรม

ถ้า `idea` ที่สกัดมายังติดบริบทเดิม ให้ตัดออกอีกชั้น:

| | |
|---|---|
| ไม่เอา | "นับจำนวนวิธีแบ่งขนมของแม่ให้ลูก 3 คน คนละอย่างน้อย 1 ชิ้น" |
| เอา | "นับจำนวนวิธีแบ่งของเหมือนกันแบบมีเงื่อนไขขั้นต่ำ" |

ยิ่ง `idea` นามธรรมเท่าไหร่ยิ่งปลอดภัย **และยิ่งสร้าง variant ได้หลากหลายกว่า** —
สองอย่างนี้ไปด้วยกัน ไม่ได้ขัดกัน `idea` ที่ติดบริบทเดิมจะสร้างได้แต่โจทย์หน้าตาเดิม

กฎเหล็กข้อ 5 (ปกต้องระบุว่าเป็นข้อสอบเทียม) ยังบังคับใช้กับชุดที่มี variant เหมือนเดิม

## ปิดวงจร

ผิดข้อไหน → ระบบรู้ไอเดียนั้นจาก `index.jsonl` → ออกโจทย์ไอเดียเดิมหน้าตาใหม่ → ผิดอีกไหม
→ วัดได้ว่าเข้าใจจริงหรือแค่จำคำตอบ

`/posn-weakness` เป็นตัวเริ่มวงจร: ถ้ามีข้อที่ผู้ใช้ผิดซ้ำในไอเดียเดียวกันเกิน 2 ครั้ง
(ดูจาก `variant_of` + `wrong` ใน `results/`) มันจะเสนอคำสั่ง `/posn-variant` ของข้อนั้นให้
**แต่ไม่รันเอง** — ผู้ใช้เป็นคนตัดสินใจว่าจะฝึกซ้ำเรื่องไหน
