# TROUBLESHOOTING — error ที่เจอจริงและวิธีแก้

## ฟอนต์

### `Package fontspec Error: The font "TH Sarabun New BoldItalic" cannot be found`
**สาเหตุ**: เรียกฟอนต์ด้วยชื่อ family (`\setmainfont{TH Sarabun New}`) fontspec เดาชื่อ
หน้า BoldItalic เป็น "TH Sarabun New BoldItalic" แต่ fontconfig ลงทะเบียนไว้เป็น
`TH Sarabun New:style=Bold Italic`
**แก้**: อ้างไฟล์ตรง ๆ ด้วย `Path` + `Extension` + `UprightFont/BoldFont/...` ดู SKILL.md หัวข้อ 1

### `Missing character: There is no m (U+006D) in font ...`
**สาเหตุ**: ใช้ฟอนต์ไทยที่ไม่มี glyph ละติน (Noto Looped Thai / Noto Serif Thai /
Noto Sans Thai ทั้งหมดไม่มีตัวอักษร a-z A-Z 0-9)
**แก้**: ใช้ TH Sarabun New ซึ่งมีครบทั้งไทยและละติน

## การจัดหน้า

### ภาษาไทยไม่ตัดบรรทัด ข้อความทะลุขอบขวา
**สาเหตุ**: ลืม `\XeTeXlinebreaklocale "th"` ภาษาไทยไม่มีช่องว่างระหว่างคำ XeTeX จึงมองทั้ง
ย่อหน้าเป็นคำเดียว
**แก้**:
```latex
\XeTeXlinebreaklocale "th"
\XeTeXlinebreakskip = 0pt plus 1pt
```

### ตัวเลือก ค. กับ ง. เขียนทับกัน
**สาเหตุ**: ใช้ `\makebox[0.44\textwidth][l]{...}` ซึ่งไม่ตัดบรรทัด เนื้อหายาวเกินกล่อง
จึงล้นไปทับกล่องถัดไป
**แก้**: เปลี่ยนเป็น `tabular` ที่ใช้คอลัมน์ `p{0.42\textwidth}` (ตัดบรรทัดได้)
ถ้ายังยาวอีกให้ใช้ `\chstack` เรียงลงมา 4 บรรทัด

### โจทย์อยู่ท้ายหน้า แต่ตัวเลือกไปหน้าถัดไป
**แก้**: ใส่ `\Needspace{5\baselineskip}` ก่อน `\item` ทุกข้อ
แทรกอัตโนมัติได้ด้วยสคริปต์ที่วนอ่านไฟล์แล้วเติมก่อนบรรทัดที่ขึ้นต้นด้วย `\item ` (ระวัง
อย่าไปแทรกใน `itemize` ข้างในโจทย์ — เช็คว่าบรรทัดขึ้นต้นคอลัมน์ 0 พอดี)

### `check_answer_key.py` บอกว่า "อ่านตัวเลือกไม่ได้ (macro ผิดรูป?)"
**สาเหตุ**: เขียนอาร์กิวเมนต์ของ `\chstack` แยกคนละบรรทัด สคริปต์อ่านอาร์กิวเมนต์ต่อกันโดย
ต้องเจอ `}{` ติดกัน มีขึ้นบรรทัดใหม่คั่นแล้วจะหยุด (LaTeX คอมไพล์ผ่านปกติ จึงไม่เห็นจากภาพ)
**แก้**: เขียน `\chstack{...}{...}{...}{...}` ให้อยู่บรรทัดเดียว แม้จะยาว

### `check_answer_key.py` บอกว่า "จำนวนข้อไม่ตรงกันระหว่างสามแหล่ง" (นับได้เกิน 50)
**สาเหตุ**: ใช้ `\begin{itemize}` ที่มี `\item` ซ้อนอยู่ในตัวโจทย์หรือในวิธีทำ สคริปต์นับ `\item`
ทั้งไฟล์ จึงนับ bullet เป็นข้อสอบไปด้วย ทำให้เลขข้อเลื่อนตั้งแต่จุดนั้นเป็นต้นไป และรายงาน
ตัวเลือกไม่ตรงเป็นสิบ ๆ ข้อ ทั้งที่เฉลยถูกหมด (LaTeX คอมไพล์ผ่านปกติ)
**แก้**: อย่าใช้ `itemize` ข้างในข้อ ให้ประกาศ macro ที่ไม่ใช้ `\item` แทน
```latex
\newcommand{\bul}[1]{\par\vspace{2pt}\noindent\hspace*{2.0em}$\bullet$~~%
  \parbox[t]{0.84\textwidth}{#1}\par\vspace{2pt}}
```

### ตัวเลือกตรรกศาสตร์ที่มีวงเล็บเหลี่ยมล้นทับกัน
**สาเหตุ**: สูตรอย่าง $\sim[(P \wedge Q) \wedge \sim R]$ ยาวเกินคอลัมน์ `0.20\textwidth` ของ `\chfour`
**แก้**: เปลี่ยนข้อนั้นเป็น `\chtwo` (คอลัมน์ละ `0.42\textwidth`) ตรวจจากภาพ PNG เสมอ
เพราะ `tabular` ตัดบรรทัดให้แต่ไม่ขึ้น Overfull warning

### เลขหน้ารวมเป็น `??`
**สาเหตุ**: `lastpage` ต้องอ่านค่าจาก .aux รอบก่อน
**แก้**: คอมไพล์ `xelatex` สองรอบเสมอ

## สัดส่วนขนาด

### สูตรคณิตศาสตร์ดูเล็ก/ใหญ่เกินเทียบกับตัวหนังสือไทย
ขนาดสูตร (Computer Modern) ผูกกับ **class size** ส่วนขนาดตัวหนังสือไทยผูกกับ **Scale**
- อยากให้ตัวหนังสือไทยเล็กลงอย่างเดียว → ลด `Scale` อย่าแตะ class size
- ถ้าลด class size สูตรจะเล็กตามไปด้วย และต้องเพิ่ม Scale ชดเชย (Scale ใหม่ = Scale เดิม × 14/ขนาดใหม่)

### วัดขนาดฟอนต์แล้วตัวเลขไม่สมเหตุสมผล
`pdftotext -bbox` คืนกล่องฟอนต์ ไม่ใช่กล่องหมึก จึงเทียบข้ามฟอนต์ต่างตระกูลไม่ได้
(เช่น ตัวเลขในเราเป็น Computer Modern สูง 12.74 pt เทียบกับข้อสอบจริงที่ตัวเลขเป็น
TH Sarabun สูง 17.56 pt — ไม่ได้แปลว่าเล็กกว่า 38%)
**เทียบเฉพาะคำภาษาไทยกับคำภาษาไทย** ที่เป็นฟอนต์ตระกูลเดียวกันเท่านั้น

## สภาพแวดล้อม

### `xelatex: command not found`
```bash
export PATH="$HOME/.TinyTeX/bin/x86_64-linux:$PATH"
```
ต้อง export ใหม่ทุก Bash call เพราะ shell state ไม่ persist ระหว่าง tool call

### `tlmgr install` ขึ้น error แต่บอกว่าติดตั้งบางตัวสำเร็จ
มักเป็นเพราะชื่อ package บางตัวไม่มีจริง (เช่น `xunicode` ที่ถูกยุบไปแล้ว) ตัวอื่นติดตั้ง
ผ่านหมด ตรวจด้วยการคอมไพล์จริงว่าขาดอะไรไหม ไม่ต้องไล่แก้ทีละตัว

### ดาวน์โหลดใหญ่ ๆ timeout
ใช้ `run_in_background: true` แล้วรอ notification อย่า chain `sleep` สั้น ๆ หลายรอบ
